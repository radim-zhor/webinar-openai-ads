Google feed vs. ChatGPT feed

Stejné, jen jinak pojmenované

  • id → item_id
  • link → url
  • image_link → image_url
  • item_group_id → group_id
  • product_type → product_category
  • variant_option → variant_dict
  • beze změny: title description price sale_price availability brand gtin mpn color size material gender age_group shipping

Jen v ChatGPT

  • seller_name povinné
  • vrácení u produktu: return_policy accepts_returns return_deadline_in_days
  • star_rating review_count u Googlu mimo feed
  • store_star_rating store_review_count u Googlu mimo feed
  • is_ads_eligible target_countries
  • ads_metadata místo custom_label

Nepřenese se

  • product_highlight
  • product_detail
  • pattern
  • custom_label_0-4
  • promotion_id
  • konverzační atributy Googlu:
  • question_and_answer
  • related_product
  • popularity_rank

Co v nich máte, přesuňte do popisu nebo atributů.

Kontext má čtyři vrstvy. Každá má ve feedu své místo.

1

2

star_rating review_count + co zákazníci řeší, přepsané jako fakta do description

3
Značka a obchodní pravidlakdo prodává, doprava, vrácení, původ

brand seller_name shipping accepts_returns return_deadline_in_days return_policy + původ v description

4
Vizuální hygienaobrázek, který produkt opravdu ukazuje

image_url additional_image_urls
